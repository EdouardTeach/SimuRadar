# ⚓ SimuRadar — Maritime Radar Simulator & Exercise Generator

> **Online application (GitHub Pages):**
> 🌐 [https://edouardteach.github.io/SimuRadar/](https://edouardteach.github.io/SimuRadar/)

> **Repository:**
> 📦 [https://github.com/edouardteach/SimuRadar](https://github.com/edouardteach/SimuRadar)

SimuRadar is an open-source maritime radar simulator, designed as a pedagogical tool for learning navigation radar, ARPA (Automatic Radar Plotting Aid) and international rules of the road (RIPAM / COLREGs). The project consists of **two complementary web applications**:

| Application | File | Role |
|---|---|---|
| 🛰️ **Simulator** | [`index.html`](./index.html) | PPI radar display, ARPA, EBL/VRM, CPA/TCPA alarms, own-ship piloting |
| 🛠️ **Exercise Generator** | [`generator.html`](./generator.html) | Exercise composition, coastline drawing, fleet, rain zones, ARPA scenarios |

Both applications share a common JSON format: an exercise created in the generator can be directly replayed in the simulator.

## 🎯 Project Overview

SimuRadar is an **offline simulator** (no network dependency at runtime)
designed as a **civil maritime training tool** for:

1. **Learning to read a radar PPI** — band selection (X / S), pulses (SP,
   MP, LP), gain control, sea/rain anti-clutter, afterglow.
2. **Understanding ARPA** — target acquisition, relative/true vectors,
   CPA / TCPA calculation, guard zone alarms.
3. **Practicing steering and navigation rules (RIPAM / COLREGs)** —
   crossing, overtaking, head-on, NUC / RAM vessels, turning.
4. **Reconstructing real-life maritime accident scenarios** from the
   integrated database (**BEA mer**, **MAIB**, DMAIB, BSU).
5. **Creating your own exercises** with the integrated generator, then
   replaying them in simulation mode.

> 🧭 *Target audience: maritime academy cadets, maritime officer students,
> recreational boating instructors, radar trainers.*

## 📚 Real-World Collision Reports — BEA mer & MAIB

The exercise generator and simulator include an **integrated case bank**
inspired by real collision reports published by the official maritime
accident investigation agencies:

- **BEA mer** (*Bureau d'enquêtes sur les événements de mer* — France):
  investigation reports on maritime accidents in French waters.
- **MAIB** (*Marine Accident Investigation Branch* — United Kingdom):
  reports on accidents involving UK-flagged or UK-waters vessels.

Each scenario can be **replayed in simulation mode** to:

- analyze the initial conditions (positions, headings, speeds),
- visualize the CPA / TCPA evolution as the encounter unfolds,
- apply the steering and navigation rules to identify the appropriate
  maneuver,
- compare the chosen maneuver with the conclusions of the official report.

> 🧪 *These exercises are pedagogical reconstructions: they are simplified
> and adapted versions of public-domain reports, intended for training
> purposes only.*

## 🌊 Main Features

### 1. 🛰️ Radar Simulator (`index.html`)

#### PPI Display
- **Bands**: X-Band (3 cm, high resolution) / S-Band (10 cm, long range).
- **Pulses**: SP (short) / MP (medium) / LP (long).
- **Orientations**: **N-UP** (north up), **C-UP** (course up), **H-UP**
  (head up).
- **Ranges**: 0.75 NM → 48 NM (standard scales).
- **Visual aids**: range rings, heading line, bearing graduation,
  re-centering, center offset in NM.

#### Echo Settings
- Brightness, gain, sea anti-clutter, rain anti-clutter, afterglow.
- Simulated degradation: noise, weak echoes, scintillation, ghost
  echoes, rain clouds.

#### Measurement Tools
- **EBL** (Electronic Bearing Line) — electronic bearing.
- **VRM** (Variable Range Marker) — variable range circle.
- **Cursor measurement** — bearing + range live (NM / °).

#### Trails & Vectors
- Simulation speed ×0.5 / ×1 / ×2 / ×4 / ×8.
- Relative / true vectors, durations (72 s, 1 min, 3 min, 6 min, disabled).
- Relative / true trails, lengths 3 → 30 points, persistence
  (None / 15 s / 1 min).

#### Ship Dynamics (own ship)
- Heading pilot (–10°, –1°, +1°, +10°) and speed (–0.5 / +0.5 kn).
- Drag and drop the own ship on the PPI or on the dedicated pad.
- "Coastal watch" and "Standby" modes.

#### ARPA & Alarms
- Real-time CPA / TCPA table for each contact.
- Detailed ARPA record (range, bearing, course, speed, CPA, TCPA).
- Configurable CPA / TCPA alarms (thresholds).
- **Guard zone** (circular) with configurable radius.

#### Scenarios
- Integrated exercise bank (BEA mer / MAIB / DMAIB / BSU + local cases).
- Loading of JSON files produced by the generator.
- Collision mode: overlay + "Restart" button.

#### Ship Types & Conditions (RIPAM)
- Cargo, Fishing trawler, Sailboat, Ferry / HSC, Tanker / VLCC, Tugboat,
  Nuclear submarine, Warship, Patrol boat.
- Conditions: none, at anchor, **NUC** (Not Under Command),
  **RAM** (Restricted in Ability to Maneuver).

#### Interface
- **Bilingual** FR / EN (saved in `localStorage`).
- **Themes** Classic / Modern (grey).
- **Responsive**: pinch-zoom, touch pan, mobile landscape mode.
- **Full-screen** available.
- **Resizable and reorganizable panels** (drag & drop between docks).

### 2. 🛠️ Exercise Generator (`generator.html`)

#### Fleet Composition
- Number of ships, types (Cargo, Ferry, Tanker, Tugboat, Fishing
  trawler, …), special conditions (**NUC · erratic route**,
  **RAM · reinforced turn**).
- **Ghost echo** per ship.
- Right-click editing: name, heading, speed, type, condition.

#### Route Creation (waypoints)
- 1 to 10 waypoints clicked on the map.
- **Pattern route generator**:
  - S-shaped / sailboat zigzag route.
  - Erratic NUC route.
  - Ferry shuttle.
  - Circular patrol / loiter.
  - Sharp turn at CPA.
  - Anti-collision (radial).
- Route editing: insertion / deletion / movement of waypoints.

#### Coastline Editing
- Available shapes: **circle / island, rectangle, elongated island,
  ellipse, strait, bay, port, archipelago, free polygon**.
- Adjustments: tilt, orientation, width, length, distance.
- Tools: mouse / touch drawing, resize handles, deletion (Del).

#### Real Coastline (basemap)
- Presets: **Marseille, Pas-de-Calais · Strait of Dover, Solent,
  Ouessant, Rade de Brest, Gibraltar**.
- Basemaps: **Esri Ocean, Esri World Imagery,
  Esri World Street Map, OpenTopoMap**.
- Import of **GPX / GeoJSON / OSM** files.
- Configurable radius.

#### Rain Zones
- Light / medium / heavy shapes.
- Adjustable intensity 0–100 %.

#### Echo Degradation
- Sea / swell, rain, background noise, weak echoes, scintillation (%).

#### OWN Starting Point (flag)
- Dedicated modal: type, condition, initial speed (kn), initial
  heading (°), orientation compass.

#### Random Generation
- Modes: Alleviate, Random mix, Standard.
- Real-case bank (BEA mer / MAIB).

#### Floating Preview
- Animated and repositionable preview window: playback, speed,
  rewind ±30 s.

#### CPA / TCPA Table
- Columns: Heading, Speed (kn), Distance, Bearing, CPA, TCPA.

#### Import / Export
- **⇧ Import** JSON exercise.
- **⇩ Export** JSON (Blob `application/json`, local download).
- **Persistence** `localStorage`.

## 🚀 How to Run SimuRadar

### Online (recommended)

1. Open the GitHub Pages URL:
   **<https://edouardteach.github.io/SimuRadar/>**
2. Choose the mode:
   - **Simulator** → [`index.html`](./index.html) to play an exercise.
   - **Generator** → [`generator.html`](./generator.html) to create one.

### Locally (on your computer)

```bash
# Clone the repository
git clone https://github.com/edouardteach/SimuRadar.git
cd SimuRadar

# Open directly in a modern browser
# (Chrome, Edge, Firefox, Safari — recent versions)
xdg-open index.html        # Linux
open index.html            # macOS
start index.html           # Windows
```

> 💡 *No installation or server is required: everything runs
> locally, without network connection.*

### Quick Tutorial — 5 Minutes

#### A. Discover the Simulator

1. Open `index.html`.
2. Click **FR | EN** to choose the language.
3. Select the **X-Band** and the **MP** pulse.
4. Choose the **N-UP** orientation and the **6 NM** range.
5. Activate **Rings ON** and **Heading Line ON**.
6. In **SHIP CONTROL**, set the heading (e.g. 090°) and the speed (e.g. 12 kn).
7. Click **▶ PLAY**: the ship starts moving on the PPI.
8. Activate **VRM ON**, set the radius, then **EBL ON**, set the bearing.
9. Click on an echo: the **ARPA record** opens (course, speed, CPA, TCPA).
10. Activate the alarms (**Alarms ON**, CPA threshold, TCPA threshold).

#### B. Create an Exercise with the Generator

1. Open `generator.html`.
2. Choose the language and theme.
3. Click **🌊 BEA mer / MAIB** to load a real case, OR
   click **↻ Generate** for a random scenario.
4. Compose the fleet:
   - Number of ships.
   - Type, condition, heading, speed.
5. Click **OWN Starting Point** → set type, speed, heading → click on the map.
6. Click **Add a coast / island** → choose the shape → draw on the map.
7. (Optional) Click **⌖ Real Coastline** → select a preset (Marseille,
   Gibraltar, …) and a basemap.
8. (Optional) Click **Rain Zone** → draw and set the intensity.
9. Click **▶ Preview** to check the simulation.
10. Click **⇩ Export** to download the exercise as a JSON file.
11. Open `index.html` → click **↻ Load Exercise** → select the
    exported JSON file → **▶ PLAY**.

#### C. Read an ARPA Record

For each contact, the ARPA table displays:

| Field | Meaning | Unit |
|---|---|---|
| **DIST.** | Distance to the own ship | NM |
| **BEARING** | True bearing of the contact | ° |
| **COURSE** | True course of the contact | ° |
| **SPEED** | Ground speed of the contact | kn |
| **CPA** | Distance to closest point of approach | NM |
| **TCPA** | Time to CPA | min |

An alarm triggers when **CPA < threshold** AND **TCPA < threshold**.
